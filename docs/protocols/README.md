# CarAutopsy Protocols

These protocols govern how humans and AI agents work on CarAutopsy.

## Required Reading Order

1. Vehicle Catalog Protocol v1.04
2. Data Rights Policy v1.01
3. Project Session Handover Protocol v1.01
4. Article-Writing Protocol v1.04, when writing public content

## Non-Negotiables

- Do not bypass site terms or access controls.
- Do not scrape EV Database or similar compiled databases.
- Do not store unverified numeric specs as official facts.
- Unknown values are `null`, not zero.
- Every statutory calculation needs a source and effective date.
- Every meaningful work session needs a handover.
